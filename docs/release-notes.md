# intentbus v0.1.0

First usable public alpha: library, command-line interface, examples and documentation.

- Node.js 22+; no runtime dependencies or build step.
- MIT license; install directly from the versioned GitHub tag.
- 16 automated tests plus syntax and TypeScript declaration checks.
- Explicitly synthetic offline demo. No live Jev quality benchmark is claimed.

See the README for supported behavior and current limits. GitHub Actions runs the test suite on Node.js 22 and 24.
